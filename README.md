# HR Analytics Dashboard | Power BI Project
 Project Overview:

The HR Analytics Dashboard is an interactive and dynamic reporting solution built using Power BI to deliver actionable insights into organizational workforce metrics. Designed for HR teams and decision-makers, this project provides a high-level overview of employee demographics, performance evaluations, promotion readiness, and workforce reduction planning.

# Workforce Key Performance Indicators (KPIs):
Tracking of overall headcount (Total Employees). 
Gender diversity analysis with calculated measures for percentages (% Male & % Female).

# Actionable HR Metrics:
Interactive tables tracking employees Due for Promotion.  
Risk & workforce management tracking for employees slated for Retrenchment.

# Seamless User Navigation:
Custom sidebar navigation using dynamic page-navigation buttons (HOME, Action, Details) to enhance visual storytelling and user experience.   Advanced DAX Logic:Safe division handling using DIVIDE() logic to prevent divide-by-zero errors.
Filtered metrics built using CALCULATE() logic for targeted performance segmentations (e.g., High Performance Ratings).
